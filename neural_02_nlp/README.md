# Программа курса "Нейронные сети для обработки текста" (2026)


## 1. Введениe
- Представление текстовых данных в компьютере: кодирование и т.д. 
- Задачи обработки текста, обзор. История подходов и методов решения (RNN, LSTM и прочие неактуальные методы). 
- Лингвистические особенности текстовой информации и их влияние на методы обработки текста.
- Большие языковые модели (LLM) и трансформеры: обзор.
- Характеристики LLM, выбор модели: кол-во параметров, контекстное окно, выбор квантования, форматы.

## 2. Загрузка текстовых данных и элементарные приемы машинного обучения для текста
- загрузка и предварительная обработка текстовых данных
- поиск по тексту в pandas (ключевые слова, регулярные выражения и т.д.)
- полнотекстовый поиск (TF/IDF, BM25 и т.д.)
- токенизация, стемминг, лемматизация и другие приемы предобработки текста

## 3. Трансформеры: как они работают
- механизм внимания: Q, K, V, Wq, Wk, Wv, softmax и т.д.
- архитектура трансформера: энкодер, декодер, многоголовое внимание, позиционные эмбеддинги и т.д.
- практика: визуализация внимания, реализация простого трансформера на PyTorch (генерация несуществующих городов)

## 4. Трансформеры на практике
- библиотека `transformers` от Hugging Face
- предобученные модели и токенизаторы
- различные pipelines для разных задач (классификация, генерация, извлечение информации и т.д.)
- дообучение предобученных моделей на своих данных (fine-tuning)

## 5. Дообучение больших языковых моделей (LLM)
- Trainer из Hugging Face для дообучения LLM
- SFTTrainer и LoRA 
- DPOTrainer (как упрощенный RLHF)
- Разметка текста, BIO-формат для NER

## 6. API больших языковых моделей
- OpenAI API и другие сервисы для доступа к LLM
- LLM как универсальное средство для решения различных задач (генерация текста, ответы на вопросы, саммаризация, извлечение информации и т.д.)
- тонкая настройка запросов: промпт-инжиниринг, роли, температура, max_tokens и т.д.
- Sber GigaChat, Yandex AI Studio
- доступ к локальным моделям через API, запуск моделей на своем компьютере или на сервере (на примере llama.cpp)
- практика программного обращения к LLM для генерации текста, ответов на вопросы, саммаризации и т.д.

## 7. RAG (Retrieval-Augmented Generation)
- Векторная БД Quadrant для хранения эмбеддингов и поиска по ним
- полнотекстовый, семантический и гибридный поиск в Quadrant
- интеграция Quadrant с LLM для создания RAG-системы
- практика создания RAG-системы для ответа на вопросы по текстовым данным (на примере рассказов Я. Гашека)

## 8. AI-агенты на основе LLM
- переход "от слов к делу" или как большие языковые модели стали фундаментом для создания AI-агентов
- архитектура AI-агента: ReAct, понятия runtime, memory, tools и т.д.
- практика создания AI-агента для разбора и анализа файлов на базе SmolAgents.
